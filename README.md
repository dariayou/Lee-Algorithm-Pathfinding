# Волновой алгоритм Ли 

Поиск кратчайшего пути на сетке с возможностью ходить:

- по горизонтали/вертикали (длина 1)
- по диагонали (длина √2) – только если соседние клетки свободны
- «конем» (2+1, длина √5) – только если промежуточные клетки свободны

Разные типы поверхности влияют на стоимость прохода:

- Обычная (стоимость 1.0)
- Болото (стоимость 3.0) – медленнее
- Асфальт (стоимость 0.5) – быстрее

## Установка и запуск

### 1. Установите PostgreSQL
Скачайте и установите PostgreSQL 

### 2. Создайте базу данных и таблицы
Откройте командную строку `psql` и выполните:

CREATE DATABASE lee_algorithm;

\c lee_algorithm;

CREATE TABLE surface_types (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    cost_factor FLOAT
);

INSERT INTO surface_types (id, name, cost_factor) VALUES
(1, 'Обычная', 1.0),
(2, 'Болото', 3.0),
(3, 'Асфальт', 0.5);

CREATE TABLE grid (
    x INT,
    y INT,
    walkable BOOLEAN DEFAULT TRUE,
    surface_type_id INT DEFAULT 1,
    PRIMARY KEY (x, y),
    FOREIGN KEY (surface_type_id) REFERENCES surface_types(id)
);

3. Установите зависимости Python

В командной строке выполните:

pip install psycopg2-binary

4. Настройте подключение к БД

В файле db_manager.py укажите свой пароль PostgreSQL (по умолчанию password). При необходимости измените имя пользователя, хост.

5. Запустите программу

python main.py

## Как пользоваться:

## Управление:

Левая кнопка мыши – установка старта (зеленый) и цели (красный).

Первый клик – старт, второй – цель, третий – перемещение старта.

Правая кнопка мыши – открывает контекстное меню для клетки:

Стена – делает клетку непроходимой (серая).

Обычная / Болото / Асфальт – устанавливает тип поверхности (клетка становится проходимой, если была стеной).


## Кнопки на панели:

Загрузить сетку – восстановить последнее сохранение из БД.

Сохранить сетку – записать текущее состояние (стены, типы) в БД.

Очистить путь – убрать синюю линию найденного пути.

Найти путь – запустить алгоритм. Если путь существует, он отобразится синими клетками, в статусной строке появится длина.

Сбросить стены – убрать все стены (оставить типы поверхности).

Сбросить типы поверхностей – все клетки сделать обычными (оставить стены).

Очистить старт/цель – удалить выбранные точки.


## Цветовая индикация:

Белый – обычная проходимая клетка.

Коричневый – болото (стоимость 3.0).

Светло-серый – асфальт (стоимость 0.5).

Серый – стена (непроходимо).

Зелёный – старт.

Красный – цель.

Синий – найденный путь.


## Требования:

Python 3.7+

PostgreSQL 12+

psycopg2-binary

main.py – графический интерфейс (tkinter) и логика взаимодействия.
